TS Academy Aurora Cohort — 30-Day DevOps Learning Challenge

About This Challenge

This repository documents my 30-day learning journey as a participant in the TS Academy Aurora Cohort — DevOps Engineering Programme.

The purpose of this challenge is to build consistency, strengthen my understanding of DevOps engineering principles, document practical learning experiences, and share my progress with the technology community.

This is a record of my actual learning activities, class experiences, exercises, challenges, and discoveries throughout the challenge.

Learning Objectives

During this journey, I aim to:

* Develop a strong foundation in DevOps engineering.
* Improve my Linux administration and command-line skills.
* Understand Git and collaborative development workflows.
* Gain practical experience with containerisation using Docker.
* Explore AWS cloud infrastructure.
* Learn Infrastructure as Code with Terraform.
* Understand CI/CD automation.
* Develop knowledge of Kubernetes, monitoring, and logging.
* Build the habit of documenting and sharing technical knowledge.

Each daily entry will capture:

1. Date and learning activity.
2. Key concepts covered.

4. Challenges encountered.
5. Lessons learned.
6. Evidence or screenshots, where applicable.
7. Link to the corresponding LinkedIn update.
