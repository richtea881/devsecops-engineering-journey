# Linux Administration & DevSecOps

Welcome to the Linux Administration module of the Four-Month DevSecOps Engineering Journey.

This space documents practical Linux administration, system management, troubleshooting, and security exercises.

## Week 01 — Linux Fundamentals

Week 01 develops foundational Linux administration skills through practical exercises and documented verification.

Topics include:

- Linux permissions and ownership
- Shared directories and Setgid
- User and group management
- Sudo and privilege management
- Process management and service administration
- Linux process control
- Process monitoring and resource management
